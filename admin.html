WordPress REST API Settings

Configure WooCommerce connection and authentication keys

💡 How to enable Read/Write permissions in WordPress (30 seconds): 1. In your WordPress Admin bar, click WooCommerce → Settings → Advanced → REST API.
2. Click on the API Key.
3. Change Permissions from Read to Read/Write, and click Save.
4. Once saved, all edits in this Admin Console will automatically update on /shop-3/ and single product pages!
